# react-native-snapbot

The debug-only Expo Router setup route and app-state hooks for
[Snapbot](https://github.com/twocentinc/snapbot). Prepare application-owned theme
and session state, then open modals, sheets, or steps for screenshots.

- [Install from source](https://twocentinc.github.io/oss/docs/snapbot/getting-started/)
- [Integrate SnapbotRoute](https://twocentinc.github.io/oss/docs/snapbot/app-integration/)
- [Use app-state hooks](https://twocentinc.github.io/oss/docs/snapbot/app-states/)
- [Security and debug-only limits](https://twocentinc.github.io/oss/docs/snapbot/security/)
- [Contribute](https://twocentinc.github.io/oss/docs/snapbot/contributing/)

The package expects the app to provide `expo-router`, `react`, and `react-native`.
It is not yet published on npm; use the source-install guide. Detailed usage
and examples live in the shared twocents documentation.
